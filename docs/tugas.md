SOAL TUGAS BESAR PRAKTIKUM
Topik: Remastering Distro Linux Ubuntu Menggunakan Cubic
1. Deskripsi Tugas
Setiap kelompok ditugaskan untuk melakukan remastering (kustomisasi ulang) pada file ISO Linux Ubuntu. Proses pengerjaan dan pengujian wajib dilakukan di dalam mesin virtual menggunakan Oracle VM VirtualBox, dengan bantuan aplikasi Cubic (Custom Ubuntu ISO Creator) untuk memodifikasi desain serta komponen sistem sesuai tema yang dipilih oleh kelompok.

2. Ketentuan Kelompok & Tema
 Jumlah Anggota: 3 orang per kelompok.
 -  Pemilihan Tema: Bebas dan ditentukan oleh masing-masing kelompok (contoh: Ubuntu for Gaming, Edu-Ubuntu untuk Sekolah, Cyber Security Edition, Desain Grafis/Multimedia, atau Perkantoran).
 - Konsep Desain: Seluruh perubahan tampilan (user interface) dan aplikasi yang ditambahkan harus relevan serta mendukung tema yang telah dipilih.

3. Spesifikasi Teknis Pengerjaan
 - Lingkungan Kerja: Seluruh tahapan pembuatan hingga uji coba (testing) ISO hasil remaster wajib dijalankan menggunakan Oracle VM VirtualBox.
 - Alat Kustomisasi: Wajib menggunakan Cubic pada sistem operasi Ubuntu dasar (base system).
 - Cakupan Kustomisasi Desain (Minimal):
 - Mengubah tampilan wallpaper bawaan (default), tema ikon, kursor, atau tampilan desktop environment agar selaras dengan tema kelompok.
 - Menambahkan paket aplikasi (pre-installed software) yang menunjang tema pilihan, serta menghapus aplikasi bawaan yang tidak diperlukan.
 - Mengubah identitas atau tampilan booting awal (splash screen / Plymouth atau GRUB) menjadi identitas distro buatan kelompok.
 - Hasil Akhir (Output): Menghasilkan file .iso baru yang bersifat bootable dan dapat diinstal maupun dijalankan (Live CD) dengan lancar pada mesin virtual baru di VirtualBox.
Format Laporan & Pengumpulan (Opsional - Sesuaikan dengan Kebutuhan)
 - Dokumentasi Laporan: Berisi nama distro baru, latar belakang pemilihan tema, daftar perubahan/aplikasi yang ditambahkan, serta screenshot langkah-langkah pengerjaan di Cubic dan hasil akhir saat dijalankan di VirtualBox.
 - Bukti Hasil: Menyertakan file ISO hasil remaster atau tautan (link) video demonstrasi singkat yang menampilkan proses booting hingga tampilan desktop utama di VirtualBox.
