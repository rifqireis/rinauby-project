# Custom Agent Rules
- Setiap kali tugas atau workflow selesai, jalankan perintah bash berikut secara otomatis:
  notify-send "Antigravity Agent" "Tugas selesai dikerjakan!"
- Jika memungkinkan, gunakanlah multi-agent untuk mempercepat tugas dan mencapai efektivitas maksimal (pertimbangkan efektifitas dan efisiensi)
- Selalu jalankan git, commit setelah mengerjakan tugas untuk memastikan semua versi kode terkontrol dengan baik
